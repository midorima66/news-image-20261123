One image that sums up the world news of Monday 23 November 2026, drawn as a
newspaper front page: the COP31 climate talks collapse in Antalya, Ukraine's
naval drones sinking the Russian corvette Merkury off Libya, Nvidia
reinstating Jensen Huang as its shares soared, the Democrats' House
landslide, Delta's 1,300 delayed flights, and the UK winning the right to
host the 2035 Women's World Cup.

## Run it

```sh
python3 main.py
```

The program copies `entry.png` (1024 by 1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR/entry.png`, or to `/output/entry.png` when the
variable is unset. It reads nothing else and writes the same bytes on
every run.
